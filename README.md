# Expense Tracker

A responsive Expense Tracker web application developed as part of the CODSOFT Frontend Development Internship – Task 3.

## About the Project

The Expense Tracker helps users manage their personal finances by recording income and expenses, calculating their current balance, and viewing transaction history.

## Features

- Add income and expense transactions
- Track total income and expenses
- Calculate current balance
- View transaction history
- Delete transactions
- Save transaction data using browser Local Storage
- Responsive and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Alternatively, use the VS Code Live Server extension.
